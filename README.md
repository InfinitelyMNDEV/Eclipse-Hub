</div><br>◈ What is Eclipse?

Eclipse Hub is a Roblox interface designed to bring features for supported games into one simple hub.

No unnecessary clutter.
No giant collection of random modules.
Just open the interface, select what you need, and go.

<br>✦ Highlights

«🎮 Supported Games
Game-specific features built around supported experiences.»

«🎨 Custom Interface
A simple UI designed specifically for Eclipse.»

«⚡ Lightweight
Built to keep the interface clean without unnecessary bloat.»

«🔄 Continuously Updated
Features and game support may change as games receive updates.»

<br>⚙️ Usage

Eclipse Hub is intended for use in supported Roblox games.

If the current game isn't supported, the corresponding features won't be available.
